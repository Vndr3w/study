# Дистрибутивы

**В этом разделе расскажем:**

1. Что такое дистрибутивы.
2. Из чего состоят дистрибутивы.
3. Чем отличаются дистрибутивы.

**Дистрибутив** — это форма распространения программного обеспечения.

**Дистрибутив обычно содержит:**

- программы для начальной инициализации системы: инициализация аппаратной части, загрузка урезанной версии системы и запуск программы-установщика;
- программу-установщик для выбора режимов и параметров установки;
- набор специальных файлов, содержащих отдельные части системы: пакеты, ядро, прикладные приложения и т. д.

Программа установки позволяет установить и произвести первичную настройку системы.

По [ссылке](https://distrowatch.com/dwres.php?resource=family-tree) вы можете ознакомиться с периодической таблицей, где перечислены существующие сегодня дистрибутивы.

**Дистрибутив состоит из:**

- ядра;
- системы инициализации;
- предустановленного и доступного набора ПО;
- графической оболочки по умолчанию, если она входит в дистрибутив;
- пакетного менеджера. Например, в deb-based это apt, в rpm-based — dnf;
- исправлений и другого ПО от разработчиков дистрибутива.

 
**Чем могут отличаться дистрибутивы**

 
1. *Архитектура*

    Тип процессоров, которые поддерживает дистрибутив:

- x86 или i586/i686 — 32-битный процессор, совместимый с Intel и AMD;
- x86_64 — 64-битный процессор, совместимый с Intel и AMD;
- ARM — архитектура процессора, оптимизированного для использования на мобильных устройствах: планшетах, смартфонах. С ARM могут работать с трудом или не работать совсем многие программные решения, которые активно используются в IT и системном администрировании, DevOps и пр.;
- PowerPC — устаревшая архитектура процессоров, применявшихся в компьютерах компании Apple.

 
2. *Система инициализации*

    **Система инициализации** — это самый первый процесс (daemon), который запускается при загрузке компьютера с ОС на базе ядра Linux и функционирует в течение всего времени работы системы.
    Система инициализации — это родительский процесс каждого последующего процесса, который запускается на устройстве: System V или SysV, systemd — используется с осями последних версий Linux, runinit, upstart — встречается в Ubuntu до 15-й версии.
    Самые популярные сегодня: Systemd и SysV.

 
3. *Пакетный менеджер*

    Дистрибутив жёстко привязан к типу пакетов, но пакетный менеджер можно выбирать. В таблице ниже представлены варианты менеджеров для разных типов пакетов.


    | Тип пакета | Пакетный менеджер                                                  |
    |------------|--------------------------------------------------------------------|
    | deb        | dpkg, apt, aptitude, gdebi                                         |
    | rpm        | rpm, yum, dnf, zypper                                              |
    | pacman     | Пакетный менеджер в Arch Linux и производных от него дистрибутивах |
    | portage    | Пакетный менеджер для Gentoo Linux, ChromeOS и производных         |

 
4. *Графическое окружение*

    В большинстве доступных дистрибутивов пользователь может изменять или устанавливать несколько вариантов рабочих столов.

    Среды рабочего стола:

    - GNOME
    - KDE
    - Xfce
    - LXDE
    - MATE
    - LXQT

    Обычно чем более визуально привлекателен GUI (graphical user interface — графический интерфейс пользователя), тем больше системных ресурсов он может потреблять. Если речь идёт об одном компьютере и одном пользователе — это не критично. В случае с терминальными серверами, где могут работать 50–100 пользователей на терминале Linux, лучше использовать Xfce, LXQT или LXDE.

    Разработчики дистрибутива могут использовать различные комбинации дисплейного сервера и графического интерфейса.
    
5. *Дополнительные источники приложений*

    У многих дистрибутивов существуют дополнительные доступные репозитории для установки приложений.

 
6. *Файловая система*

    По умолчанию файловая система Linux стандартная: разбиение по каталогам и подкаталогам. Но могут быть небольшие отличия.

 
7. *График релизов*

    Дистрибутивы могут отличаться частотой и регулярностью выхода новых версий.

 
8. *Цели*

    Дистрибутив может быть общего назначения, а может быть создан для выполнения узкоспециализированных задач.

 
9. *Философия*

    Отношение к проприетарному коду у дистрибутивов может отличаться.
    Выбирая операционную систему, убедитесь, что она совместима с различными репозиториями и для неё создаются готовые пакеты.

# RPM-based дистрибутивы
 
**В этом разделе мы расскажем о:**

- Некоторых RPM-based дистрибутивах
- Сферах применения RPM-based дистрибутивов

RPM-based дистрибутивы поддерживают пакетный менеджер RPM.
 
**RHEL**

[RHEL (Red Hat Enterprise Linux)](https://www.redhat.com/en/technologies/linux-platforms/enterprise-linux) — это популярный дистрибутив на основе RPM, разработанный и поддерживаемый Red Hat Inc. Он предназначен для развёртывания на уровне предприятия и предлагает долгосрочную поддержку. Red Hat Inc развивает платную программу сертификации и обучения своим продуктам.
RHEL считается стабильным и одним из самых надёжных дистрибутивов.
 
**CentOS**

[CentOS (Community Enterprise Operating System)](https://www.centos.org/) — это поддерживаемый сообществом дистрибутив, основанный на коммерческом Red Hat и совместимый с ним:

- CentOS 7 — поддержка до 2024 года
- CentOS 8 — поддержка прекращена. На смену пришёл CentOS Stream
- новые пересборки RHEL — Rocky Linux, AlmaLinux

 
**Fedora**

[Fedora](https://fedoraproject.org/ru/) — дистрибутив Linux, спонсируемый фирмой Red Hat и содержащий возможности, которые в будущем предполагается использовать в дистрибутиве Red Hat Enterprise Linux. Часто используется разработчиками и опытными пользователями в качестве настольной или серверной операционной системы.
Начало разработки — 2003 год.

 
**openSUSE, SUSE**

[openSUSE](https://www.opensuse.org/), [SUSE](https://www.suse.com/products/) — дистрибутив, основанный на Slackware.
SUSE — коммерческая версия, выпускаемая одноимённой немецкой компанией.
Позиционируется как стабильный и надёжный дистрибутив для корпоративного использования.
Начало разработки — 2004 год.

 
**МСВС**

МСВС (Мобильная Система Вооружённых Сил) — защищённая операционная система общего назначения, созданная на базе RHEL. Используется в Вооружённых силах РФ.

 
**РЕД ОС**

[РЕД ОС](https://redos.red-soft.ru/) — операционная система на базе ядра Linux, составной продукт, построенный на базе решений с открытым исходным кодом и собственных разработок. Занесена в Единый реестр российских программ.
Начало разработки — 2017 год.
 
Это лишь несколько примеров основных дистрибутивов RPM и их распространённых вариантов использования. Каждый из этих дистрибутивов имеет сильные и слабые стороны, и выбор конкретного решения зависит от потребностей и требований.

# DEB-based дистрибутивы

**В этом разделе мы расскажем:**

- Какое ПО поддерживают дистрибутивы DEB-based
- Какие особенности у этого ПО

DEB-based дистрибутивы поддерживают ПО, упакованное в DEB-пакет.
 
**Debian**

[Debian GNU/Linux](https://www.debian.org/) — один из старейших и самых популярных дистрибутивов на основе DEB. Впервые выпущен 16 августа 1993 года. Он считается одним из самых стабильных дистрибутивов и имеет наибольшее хранилище пакетов.
Debian заявляет о себе как о свободном дистрибутиве и имеет строгую политику в отношении проприетарного ПО, то есть они не включают репозитории с проприетарным ПО в свою систему по умолчанию. Debian используется в различных отраслях, включая веб-хостинг, образование и правительство.
Используя Debian, вы соглашаетесь на Debian Social Contract.

 
**Ubuntu**

[Ubuntu](https://ubuntu.com/) — это популярный дистрибутив, производный от Debian, который прост в использовании и установке. Он известен удобным интерфейсом, хорошо документирован, имеет большую базу пакетов, полностью совместим с репозиторием Debian. Дистрибутив ориентирован на удобство и простоту использования.
Ubuntu широко используется в настольных, образовательных и серверных средах.

 
**Linux Mint**

[Linux Mint](https://linuxmint.com/) — развиваемый сообществом популярный дистрибутив на основе Debian и Ubuntu.
Для Linux Mint было разработано графическое окружение Cinnamon.

 
**Astra Linux**

[Astra Linux](https://astralinux.ru/) — российская операционная система, разработанная ООО «РусБИТех-Астра», на основе Linux-дистрибутива Debian с изменением внутреннего устройства и различных программ. Дистрибутив прошёл проверки и лицензирование со стороны госорганов РФ для применения в госструктурах.

# Другие дистрибутивы общего назначения

**В этом разделе мы расскажем:**

- какие ещё существуют дистрибутивы общего назначения

Эти дистрибутивы обладают широкими возможностями настройки для использования в разных сферах.

 
**Arch Linux**

[Arch Linux](https://archlinux.org/) — это независимый дистрибутив Linux, который следует принципу «сделай сам», позволяя пользователям выбирать и устанавливать только те пакеты и программное обеспечение, которые им нужны. Arch Linux использует пакетный менеджер Pacman.
Начало разработки — 2001 год.

 
**Gentoo Linux**

[Gentoo Linux](https://www.gentoo.org/) — это дистрибутив Linux с широкими возможностями настройки. Он известен системой управления пакетами Portage, которая совмещает возможности конфигурирования и настройки, а также автоматизированную систему управления пакетами. Особенность дистрибутива — возможность оптимизации под аппаратное обеспечение.
Начало разработки — 1999 год.

 
**NixOS Linux**

[NixOS Linux](https://nixos.org/) — это дистрибутив Linux, использующий оригинальный менеджер пакетов, вокруг которого строится идеология дистрибутива. При использовании NixOS могут возникать трудности с наличием готовых пакетов под эту ОС.
Начало разработки — 2003 год.

# Дистрибутивы Linux специального назначения
 
**В этом разделе мы расскажем:**

- Какие существуют дистрибутивы Linux специального назначения
- Для чего используются эти дистрибутивы

 
**Дистрибутивы для серверов предприятий**

Эти дистрибутивы обладают высокой надёжностью и стабильностью. Поэтому чаще всего встречаются на промышленных серверах:

- RHEL, CentOS — коммерческая и свободная версии дистрибутива от Red Hat
- Ubuntu (server/desktop) — серверная и десктопная версии от компании Canonical, возможна коммерческая поддержка
- SUSE Linux Enterprise (server/desktop) — серверная и десктопная версии от компании SUSE, возможна коммерческая поддержка
- Oracle Linux — версия Linux от компании Oracle, основана на Red Hat, возможна коммерческая поддержка

 
**Дистрибутивы для обслуживания ПК**

У многих антивирусов есть подобный дистрибутив, например:

- Dr.Web Live CD — позволяет загрузиться с Live CD и проверить систему на вирусы.
- Clonezilla LiveCD — позволяет клонировать раздел или запоминающее устройство целиком.
- SystemRescueCD — позволяет решать разнообразные административные задачи при загрузке с LiveCD. Поддерживает многие файловые системы, LVM, работу с сетью.

 
**Дистрибутивы для старых компьютеров**

Помимо современных и многофункциональных, есть малогабаритные дистрибутивы.

| Название         | Основан на                               | Системные требования       | Ядро | Оконный менеджер | Лицензия       |
|------------------|------------------------------------------|----------------------------|------|------------------|----------------|
| AntiX            | Debian                                   | 128 МБ ОЗУ и 1 ГБ          | 5.6  | IceWM            | GPL2           |
| Damn Small Linux | Debian                                   | CPU – 486DX, RAM – 16 MB   | 2.6  | Fluxbox          | GPL2           |
| Puppy Linux      | Ubuntu                                   | CPU – Pentium, RAM – 32 MB | 4.15 | JWM              | GPL, LGPL, BSD |
| Slitaz           | Ядре Linux и программном обеспечении GNU | CPU – i486, RAM – 16 MB    | 2.6  | Openbox          | GPL, другие    |

Из представленных Slitaz и Damn Small Linux самые компактные: требуют для работы 16 мегабайт оперативной памяти.

 
**Дистрибутивы для пентеста**

Пентест (pentest, жарг. от «тестирование на проникновение») — метод оценки безопасности компьютерных систем или сетей средствами моделирования атаки злоумышленника.
Эти дистрибутивы содержат разнообразные утилиты для тестирования безопасности информационных систем:

- Kali Linux, ранее известный как BackTrack — самый известный и популярный дистрибутив для тестирования безопасности
- Parrot Security OS — похожий на Kali дистрибутив (используют общие репозитории), менее требователен к ресурсам

 
**Дистрибутивы с усиленной безопасностью**

Эти дистрибутивы предназначены для защиты от киберугроз и сохранения анонимности:

- Qubes OS — использует множество Xen виртуальных машин для создания изолированных рабочих окружений, можно запускать каждое приложение в отдельной виртуальной машине
- Tails — все соединения маршрутизируются через сеть Tor

Российские разработки:

- МСВС — сертифицированная ОС для работы в ВС РФ
- Astra Linux — сертифицированная ОС для работы в МВД, госорганах

 
**Дистрибутивы для мобильных устройств**

- Android — разработанная компанией Google ОС для мобильных устройств
- Ubuntu Phone/Tablet/IoT — версия Ubuntu, рассчитанная на работу на мобильных устройствах
- Sailfish OS — мобильная ОС, частично совместимая с Android
- Firefox OS — версия мобильной ОС от Firefox

Все, кроме Android, уже не используются.

 
**Дистрибутивы для сетевых устройств**

- OpenWrt — версия ОС для встроенных систем
- Zeroshell — версия ОС для встроенных систем и серверов
- RouterOS — версия ОС для маршрутизаторов. Разработана компанией MIkroTik и используется на оборудовании этой компании
